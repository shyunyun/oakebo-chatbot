# 데이터셋 챗봇 실습 틀

고려대학교 「디지털인문학응용」 2026년 2학기 실습 도구

**바로 사용하기: https://ku-dh-chatbot.streamlit.app/**
설치 없이 위 주소로 접속하여 API 키, 프롬프트문, 데이터셋 ttl을 넣으면 됩니다.

> 이 템플릿은 Claude Opus 5.5(Anthropic)로 작성하고 강의자가 검토했습니다.

## 파일 구성

| 파일 | 내용 | 조에서 |
|---|---|---|
| `team_config.py` | 챗봇 이름, 모델, temperature, 전시 모드 등 설정 | **채운다** |
| `prompt.txt` | 프롬프트문 | **채운다** |
| `data.ttl` | 데이터셋 (여러 개면 `data`로 시작하는 `.ttl` 파일) | **올린다** |
| `greeting.txt` | 대화를 시작할 때 챗봇이 먼저 건네는 말 | 필요하면 채운다 |
| `questions.txt` | 추천 질문 (한 줄에 하나, 6개 이하) | 필요하면 채운다 |
| `notice.txt` | 전시 모드에서 화면 위에 띄울 고지문 | 전시 때 채운다 |
| `app.py` | 앱 화면 | 열지 않아도 됨 (화면을 더 바꾸고 싶을 때만) |
| `engine.py` | Gemini API 호출 | 수정 금지 |
| `ttl_to_text.py` | ttl을 문장형 텍스트로 바꾸는 모듈 | 수정 금지 |
| `requirements.txt` | 설치 목록 | 수정 금지 |
| `sample_prompt.txt`, `sample_data.ttl` | 시험용 예시(흥보가) | 참고용 |

텍스트 파일이 없거나 비어 있으면 그 기능은 쓰지 않습니다.
API 키는 어떤 파일에도 적지 않습니다.

## 우리 조 챗봇 만들기

1. 강의자 저장소의 파일을 모두 내려받아, 우리 조 저장소에 올립니다.
2. `team_config.py`를 열어 따옴표 안의 값과 숫자만 바꿉니다.
3. `prompt.txt`에 프롬프트문을 붙여 넣고, 데이터셋을 `data.ttl`이라는 이름으로 올립니다.
4. 필요하면 `greeting.txt`, `questions.txt`에 첫 인사와 추천 질문을 씁니다.
5. 우리 조 저장소를 Streamlit에 배포합니다. (아래 "배포" 참고)
6. 앱 화면 위쪽의 **"우리 조 설정 확인"**을 열어, 파일과 설정을 제대로 불러왔는지 확인합니다.
   잘못된 곳이 있으면 이 칸에 한국어로 표시됩니다.

실습 모드에서는 저장소의 `prompt.txt`와 `data.ttl`이 자동으로 들어가 있습니다.
화면에서 프롬프트문을 고치거나 다른 파일을 올려 시험할 수 있으며, 이렇게 고친 내용은 저장소 파일을 바꾸지 않습니다.
마음에 드는 결과가 나오면 그 내용을 저장소의 파일에 반영합니다.

### 강의자가 실습 틀을 고쳤을 때
`app.py`, `engine.py`, `ttl_to_text.py`만 새 파일로 바꿔 올리면 됩니다.
우리 조가 채운 `team_config.py`와 텍스트 파일은 그대로 둡니다.
(`app.py`를 직접 변형한 조는 바꾼 부분을 새 파일에 다시 옮겨야 합니다.)

## 화면을 더 바꾸고 싶을 때 (선택)
대화 상대 선택 버튼, 딜레마 선택 버튼처럼 화면 구성을 바꾸려면 `app.py`의 ✏️ 표시 부분을 고칩니다.
각자 쓰는 LLM(ChatGPT, Claude, Gemini 등)에 `app.py`를 붙여 넣고 수정을 요청해도 됩니다.
코드 맨 위 주석에 수정 범위가 적혀 있어서 LLM이 그 범위를 따릅니다.

    요청 예: "이 app.py를 우리 조 챗봇 컨셉(○○)에 맞게 바꿔 줘. 파일 맨 위 주석의 수정 범위를 지켜 줘."

AI를 써서 변형했다면 `team_config.py`의 `AI_USE_NOTE`에 어떤 도구로 무엇을 바꿨는지 적습니다.

## 배포 (Streamlit Community Cloud)
1. share.streamlit.io → New app → 우리 조 저장소 선택, Main file path에 `app.py` 입력 → Deploy
2. 나온 주소로 접속합니다.

## 전시 모드 (학회·시연용)
참여자가 링크만 눌러 바로 대화할 수 있는 화면입니다.

- 저장소의 `prompt.txt`, `data.ttl`, `greeting.txt`, `questions.txt`, `notice.txt`를 그대로 씁니다.
- 모델과 temperature는 `team_config.py`의 값으로 고정됩니다.
- API 키·모델·파일 업로드 칸, 지시문 미리보기, 대화 기록 내려받기는 보이지 않습니다.
- 다음 참여자를 위한 "새 대화 시작" 버튼이 나타납니다.
- 동시 접속이 몰리면 참여자용 안내 문구가 한국어와 영어로 나타납니다.

### 전시 모드 켜기 (키를 관리하는 사람이 할 일)
앱 설정 → Secrets에 아래 두 줄을 넣습니다.

    GEMINI_API_KEY = "행사용 키"
    EXHIBIT_MODE = true

- Secrets의 `EXHIBIT_MODE`를 지우면 같은 주소가 다시 실습 화면으로 돌아갑니다.
  (`team_config.py`에서 `EXHIBIT_MODE = True`로 바꿔도 전시 모드가 켜집니다.)
- 파일이나 키가 빠져 있으면 화면에 "[관리자 확인 필요]" 안내가 나타납니다.
- 행사가 끝나면 키를 Secrets에서 지우고, 발급처에서도 키를 삭제합니다.

주의: 전시 모드의 앱 주소를 아는 사람은 누구나 행사용 키로 호출할 수 있습니다.
행사 전용 키를 따로 발급하고, 행사가 끝나면 바로 삭제합니다.
